# ReKnee AI — Code Review & Refactoring

## Review Against
PRD, DESIGN, ARCHITECTURE, DATABASE, API, AGENTS.

## Review Areas
- correctness;
- security;
- authorization;
- architecture;
- type safety;
- duplicated code;
- dead code;
- dependency bloat;
- error handling;
- performance;
- accessibility;
- responsive UI;
- maintainability.

## Refactoring Rules
- Do not refactor merely for aesthetics.
- Preserve working behavior.
- Prefer local improvements.
- Remove dead code only when verified unused.
- Avoid speculative abstractions.

## Required Checks
- build;
- type-check;
- lint;
- relevant tests;
- manual core journey.

## Output
Classify findings:
- blocker;
- high;
- medium;
- low;
- informational.

Report changed files and remaining technical debt.
